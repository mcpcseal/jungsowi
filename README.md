## Overview

A fun parody casino site featuring a fictional Korean military officer character ("Jungsowi" / 정소위).
Built with React + TypeScript + Vite.

### Games

- 🎰 **Slot Machine** — Military-themed slots with up to 100× payout
- 🃏 **Baccarat** — Classic baccarat with Player / Banker / Tie betting

## Tech Stack

- React 19
- TypeScript
- Vite
- ESLint (typescript-eslint)
